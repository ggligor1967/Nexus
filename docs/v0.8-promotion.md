## Delivered scope

```text
1. Pure deterministic diffPlans(previous, next)
   - src/lib/diff/plan.ts; returns a structured PlanDiff with hasAnyChange
   - mirrors the pure style of the Markdown export: identical inputs -> identical output
   - no I/O, no mutation of the input snapshots; safe in a server component or unit test
   - scalar diffs (before/after/changed) + set-based, order-insensitive string-array diffs
     (added / removed / unchanged) + index-paired prototype-option diffs
2. Read-only DiffView
   - src/components/DiffView.tsx; presentational only, no state, no data fetching, no controls
   - omits unchanged sections for signal; renders an empty-state when hasAnyChange is false
3. Inline render on the existing revision snapshot route
   - /projects/[id]/revisions/[revisionId] renders <DiffView> above the two full snapshots
   - guarded by `previous && next` (nothing to compare if either snapshot is missing)
4. No new route
5. No DB / RLS / service-role / write-path changes
6. exportablePlanMarkdown excluded from the diff (same exclusion the Markdown export applies)
```
